## Om programmet kraschar

Krashrapporter sparas automatiskt här:

```
%APPDATA%\MiniDAWLab\crash-dumps\
```

(Klistra in sökvägen i Utforskarens adressfält.)

Skicka tillbaka följande:

1. Hela mappen `crash-dumps` (zippa den gärna).
2. Filen `%APPDATA%\MiniDAWLab\last-operation.txt`.
3. Projektfilen du arbetade med, om det är okej att dela den.
4. En kort beskrivning: vad gjorde du precis när det kraschade? Vilka
   tredjepartsplugin (t.ex. AmpliTube) var laddade?

Om ett projekt inte sparades innan kraschen: starta programmet igen — om en
autosparning finns får du en fråga om att återställa den.
