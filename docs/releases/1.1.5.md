# Danielssons Audio Lab 1.1.5

| | |

Export release: fixes the MP3 export hang, the leftover WAV and the blank progress window, and
adds a working progress bar with Cancel. Project-file schema is unchanged (23).

## Fixed

- **MP3 export no longer hangs at the end.** LAME's console output exceeded the pipe that DAL
  never read, so LAME blocked and the export waited for a 10-minute timeout. The encoder's
  output is now drained continuously; the same 40 s file encodes in well under a second.
- **No WAV left beside the MP3.** The intermediate WAV is a private working file in the system
  temp folder and is removed on every exit path (success, error, timeout, cancel), together with
  the working MP3. The export folder receives exactly the chosen file. WAV export never starts
  MP3 encoding. Nothing but the export's own uniquely named working files is ever deleted.
- **Progress window paints and responds.** JUCE 8's Direct2D renderer never painted the window
  while the export blocked the message thread ("white box"). The window now uses the software
  renderer and services its own messages: phase text (`Rendering... NN%`, `Encoding MP3... NN%`
  with LAME's real percentage, `Finalizing...`), a working **Cancel** button and Escape, and the
  window can be moved. Cancel stops LAME, removes working files and never touches the
  destination. The app is not flagged "not responding" any more.
- **Pre-gain refusal is no longer silent.** Undoable edits — pre-gain included — are refused
  while recording or during the count-in; the Inspector now says so instead of quietly snapping
  the field back. The pre-gain signal chain itself was measured on every production path
  (including a real AmpliTube 4 instance and the realtime engine via the audio device) and
  applies exactly once; see `docs/PREGAIN_EXPORT_VERIFICATION_2026-09-30.md`.

## Verification tooling

- New focused harness `MixdownPreGainFocusedTests` (production domain/session/mix-helper/VST3
  insert code, pre-fix LAME hang reproduction, production encoder, on-screen progress window).
- New in-app scenario `--stability-pregain`; `--stability-mixdown` now asserts the exact result
  file set, temp cleanliness, a controlled write failure and playback health afterwards.

## Known limits

- Recording still captures one armed audio track at a time.
- Capacity for a 10-minute, 150-track project has not been measured.
- Full plugin delay compensation, a low-latency tracking mode and calibrated
  recording-latency compensation remain future work.
