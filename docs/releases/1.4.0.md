# Danielssons Audio Lab 1.4.0

| | |
|---|---|
| Version | 1.4.0 |
| Date | 2026-10-25 |
| Installer | `DanielssonsAudioLab-1.4.0-Setup.exe` |
| Portable | `DanielssonsAudioLab-1.4.0.zip` |

Several MIDI events can be edited in one piano roll, and each effect insert has its own
Active, Bypass, and preset commands. Project format stays **v32**. The read-ahead on/off
choice is unchanged from 1.3.1: the Audio Settings checkbox still applies at
the next start, a saved Off stays Off, and a start argument is not written to the preference
file.

## New

- **One editor for several MIDI events.** Open an instrument's events together. They stay
  separate events. Moving, resizing, deleting, copying, and pasting notes across them is one
  undo step. Extending a note past its event asks whether to extend the event, keep the
  boundaries, or cancel.
- **Note colours are roles, not velocity.** The active event is red, other events are a
  muted red, a selection is black with a red edge, and notes outside their own event are
  grey. The velocity lane keeps its colour scale. Note names are shown on every event's
  bars when the bar is large enough, including events that are not the one being edited.
  Drum diamonds stay unmarked.
- **Audition stays on the event's own instrument.** A note plays through the instrument that
  event is routed to. An event with no instrument stays silent instead of borrowing another.
- **Active and Bypass per effect.** Each insert has its own host Active and Bypass. Bypass
  keeps the effect running for a dry comparison and does not write the plug-in's own bypass
  parameter. Turning Active off stops that insert.
- **Preset and settings commands** on the shared insert toolbar: Load preset, Save preset,
  Copy settings, and Paste settings.
- **Arrangement selection.** A marquee can select events across tracks and move them as one
  undo step. Delete, Cut, Copy, and Paste act on that whole selection, and undo restores it.
- **Per-event audio level.** Each audio event has its own gain and linear fades, applied
  before the track's effects.
- **Effect tails.** Stopping the transport keeps note releases and insert tails moving. An
  active audio insert chain keeps running through the silence outside an event so the tail
  reaches the mix. Trimming a MIDI event follows the part you see while you drag.
- **Windows.** The main window comes forward when DAL starts and when a project has finished
  opening. Opening a project restores its mixer window. Mixer channels show only the sections
  in use, and the channel number is only as wide as its digits.
- **Opening and closing projects.** A project closes one plug-in at a time, and an instance
  is released only after the audio callback and read-ahead have left it. A matching VST3
  description is reused while loading until the plug-in file changes.

## Known

- Read-ahead still starts or stops only at the next launch. Restart DAL after changing the
  Audio Settings checkbox. The renderer itself is still the 1.3.0 prototype.
- Project format stays **v32** (insert Active and Bypass). Versions 29 and 30 stay rejected:
  the Volume/Pan automation branch is not in this release. Older projects still open.
- An event with no instrument destination can be edited, but its notes make no sound.
