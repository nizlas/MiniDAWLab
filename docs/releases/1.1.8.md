## Investigation result (export clicks / distortion)

- The realtime Stereo Out and the offline export are the **same signal**: sample-identical for
  deterministic material, same fader / pan / mute / master gains, LAME keeps the level.
- **Distortion = the mix exceeded 0 dBFS** (the user's export peaked at +2.6 dBFS with 1 852
  samples over full scale at Stereo Out 0 dB; at −5 dB it is clean). Not a rendering fault.
- **Clicks = a constant DC offset from VB3-II (user's preset) once it has played**: −4.4 dBFS raw,
  present in realtime too (inaudible there because it never steps), baked into the file from the
  first sample so every export starts and ends on a step. The plug-in's behaviour — DAL now shows it
  instead of hiding it (no DC filter, no fades, no limiter were added).

## Added

- **Level meters in the Inspector**: a fixed channel panel under the (now scrollable) Inspector
  content shows the active row's name, its Channel Volume as a vertical fader (−∞ … +6 dB, graded
  scale, value field, Ctrl/Cmd+click = 0 dB), its output meter (after inserts, fader and pan) and an
  always-visible compact Stereo Out meter. 0 … −60 dBFS sample peak, L/R bars, 2 s peak hold, held
  peak number never capped at 0 dBFS, sticky red overload lamp (click to reset), "DC" tag when a
  track or the master carries a constant offset. Master row: one fader + one meter; MIDI rows: only
  the Stereo Out meter.
- **Export result shows the measured levels**: peak L/R, an explicit OVERLOAD line (samples above
  full scale) and a DC OFFSET line, in the completion message and in `mixdown-diag.log`.
- Diagnostics: `--stability-export-levels <project>` (realtime vs float / 24-bit / MP3 with the
  Stereo Out fader at its value and 12 dB lower, per-track sweep), `--stability-inspector-panel
  <project>`, `ExportLevelFocusedTests` (`--analyze <dir>`, `--timeline <wav>`,
  `--probe-vst3-dc <bundle> <project> <trackId>`).

## Changed

- The Channel volume text field moved from the Inspector's scroll area into the channel panel
  (same setter, same persistence: linear gain, −∞ stored as 0).
- Inspector default width 160 px (was 90); collapsible / resizable as before.

## Known, unchanged

- Exports start from the plug-ins' current state (no reset / pre-roll) — a tail from previous
  playback can appear in the first blocks; deliberately left for a separately verified slice.
- AmpliTube 4 teardown crash (`0x7675E`) remains intermittent at shutdown / project reload.
