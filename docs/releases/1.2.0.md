# Danielssons Audio Lab 1.2.0

| | |
|---|---|
| Version | 1.2.0 |
| Date | 2026-10-07 |
| Installer | `DanielssonsAudioLab-1.2.0-Setup.exe` |
| Portable | `DanielssonsAudioLab-1.2.0.zip` |
| Tested code | `1257d64` on `main` (this release adds only the version bump and these notes) |

The arrangement slice tested since 1.1.19: Solo with four persistent Solo memories, five shared
track heights on one snapping grid, type icons / order numbers / track colours in the headers,
visual collapsible track groups, and the follow-up UI and scroll fixes. Audio engine, routing,
plug-in handling and the parallel instrument rendering from 1.1.18 are unchanged. Architecture:
`docs/CURRENT_ARCHITECTURE.md`.

## New

- **Solo and four Solo memories.** An S cell on every audio, instrument, MIDI and Group row
  (Stereo Out has none). Solo keeps the chosen tracks audible together with what they need to be
  heard (their output chain and sends, a Group's feeders, the MIDI source of a soloed instrument).
  Four persistent Solo memories (toolbar 1–4) store Solo pictures with the project; a memory
  change is one narrow undo step. While Solo is active, Mute edits are locked (the M cell shows a
  small lock); the stored Mute states return when Solo is released. Project format v25 fields.
- **Track heights Micro / Mini / Small / Medium / Large** in the toolbar dropdown: 28 / 42 / 56 /
  98 / 196 px on one grid (14 px steps), applied to every row in one pass and used as the default
  for new tracks. Individual bottom-edge resizing snaps to the same grid (ties up, stable back and
  forth); heights above Large are ordinary steps up to a safety cap; **Custom** is shown as status
  when rows differ. Micro rows paint events as thin fields showing their time extent; Mini rows
  show waveforms / MIDI notes without the event name; Small and up add the name. Saved heights and
  the chosen preset persist (v26); older saved heights load unchanged and read as Custom.
- **Type icons, order numbers and track colours.** Each header starts with a coloured segment
  carrying the track type (waveform, keyboard, MIDI connector, Group, Stereo Out) and the track's
  current 1-based position (not an id — it follows insert / duplicate / delete / reorder). Power,
  Mute and Solo sit on the title row at every height; Monitor, Record, instrument editor and
  alternatives on a second row when the height allows. Right-click on the segment opens a muted
  palette (default grey, blue, teal, green, ochre, orange, red, purple); the colour tints the
  segment and the track's event bodies, Duplicate inherits it, and a colour change is one narrow
  undo step. Saved per track in **project format v28**.
- **Visual collapsible track groups.** Select adjacent headers (click / Shift-click), right-click
  → "Create collapsible group…". A group has a small chevron button (collapse / expand) and a
  name label at its top edge (long press ≈ 0.5 s renames; right-click: Expand / Collapse, Rename,
  Ungroup). Collapsed, the group becomes one compact block — the name plus a 4 px grey strip per
  member showing its clips, 1 px apart — while every member keeps its normal height for the next
  expand. Groups are purely visual: no routing, no bus, no audio change; moving a track into or
  out of a group is refused with the group's name. Saved with the project (v27).

## Fixed

- Group controls no longer overlap Power / Mute / Solo or the resize band of the row above; row
  separators no longer cut through them; a collapsed block follows vertical scrolling (it used to
  stay behind as ghost strips) and keeps a readable height even for two-track groups.
- After deleting a member so that a group dissolved, the remaining track could not be grouped
  again; it can now (the leftover membership is taken over by the new group). Ungroup followed by
  a new group over the same or an overlapping interval works as before.
- MIDI and audio events share the same vertical margin; the colour segment reaches the row
  separator; selected headers show one flat tint without a blue frame.

## Compatibility

- Projects saved by 1.2.0 use **format v28**. Older DAL builds cannot read v28 (and older
  format changes since 1.1.19: v25 Solo memories, v26 heights, v27 groups), so a project saved
  here needs 1.2.0 or newer on the receiving machine. Older projects open as before: no colours
  (default grey), saved heights kept, no groups.

## Verified for this delivery

- Focused tests of the changed areas are green (`SoloFocusedTests`, `TrackRowHeightFocusedTests`,
  `TrackHeaderColumnFocusedTests`, `CollapsibleTrackGroupFocusedTests`, `InputRoutingFocusedTests`,
  `MixerFocusedTests`, `MiniDAWSelftests`); real-mouse checks of the group controls and the
  header selection in the running app; the developer's manual listening / UI pass on `1257d64`.
- Audio-thread profile of the 100-track load-test project (Release `1257d64`, ASIO Fireface USB,
  48 kHz, **actual buffer 512**, Cubase closed, mixer closed, bars 17–30): callback **5.81 ms
  mean / 11.22 ms max**, **1 deadline overrun in 1 784 blocks**, 48 instruments live on 7 render
  workers (generation 1.6 ms wall), 18 AmpliTube 4 + 32 other inserts processed serially (4.0 ms
  mean, 9.4 ms max), no clipping. This is one measurement on one machine with one project: it is
  not a guarantee of click-free playback and not a performance promise for another computer. The
  crackle reported earlier that evening disappeared when Cubase (≈ 7 cores of competing load)
  was closed.

## Known

- **AmpliTube 4 teardown crash** (`AmpliTube 4.vpa+0x7675E`) remains intermittent at application
  exit and when a project with AmpliTube instances is replaced by another. Save before switching
  projects; the crash happens after the project data is written.
- At 512 samples the serial insert chains (18 live AmpliTube 4 instances in the load test) are the
  remaining bottleneck on the test machine; 1024 has more margin. Parallel insert processing is
  not part of this release.
- Between two Micro or two Small rows an expanded group shows only its chevron (the name is the
  button's tooltip); the chevron covers the leftmost 16 px of the previous row's resize band.
- Retiring a loaded 100-track project when opening another is one ≈ 15 s synchronous step.
