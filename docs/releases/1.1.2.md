# Danielssons Audio Lab 1.1.2

| | |
|---|---|
| Version | 1.1.2 |
| Date | 2026-09-26 |
| Installer | `DanielssonsAudioLab-1.1.2-Setup.exe` |
| Portable | `DanielssonsAudioLab-1.1.2.zip` |

Bug-fix release covering MIDI-track parity and Secondary-instrument sound
design. Project-file schema is unchanged (23).

## Fixed

- **Secondary instrument is audible while its own editor is open** — with a
  loaded Primary, the Secondary instance was left out of the playback snapshot
  entirely and never processed audio, so opening its plug-in editor to dial in
  a sound produced silence, including from the plug-in's own keyboard. A
  loaded Secondary is now auditioned while its native editor is open and the
  transport is stopped, even when the Primary is the track's current source.
  Closing the editor ends the audition. Notes played in DAL's MIDI editor
  still go to the Primary, so exactly one instrument sounds per note; the
  Primary/Proxy/Secondary priority order, proxy rendering and offline mixdown
  are unchanged, and the Secondary is never auditioned during playback.
  (Widens the PID-008 audition split; `docs/PORTABLE_INSTRUMENTS_AND_PROXIES.md`
  §17 and the PID-008 register entry were updated with it.)
- **MIDI file import onto MIDI tracks** — "Import MIDI file..." accepted only
  instrument rows and refused plain MIDI tracks, even though both kinds store
  clips in the same controller.
- **Moving MIDI clips between MIDI and instrument tracks** — the arrangement
  drag only treated instrument lanes as drop targets, and the move required
  instrument rows at both ends. Both directions now work in one undoable step,
  carrying the clip's notes and CC data.
- **Copy, paste and delete of MIDI clips on MIDI tracks** — the same
  instrument-only restriction blocked the clipboard shortcuts on MIDI rows.

## Verification

- `--stability-midi-track-parity` (new in 1.1.1): writes a Standard MIDI File
  from a MIDI row's clip, imports it back through the production parse-and-
  append path, moves it to an instrument row and back through the production
  cross-track move, then saves, reloads and asserts the notes are intact. It
  fails on the pre-fix code.
- `--stability-midi-routing`: unchanged pass, so MIDI delivery to a
  destination instrument and the v18 round-trip still behave.
- The Secondary audition rule is a pure predicate
  (`instrument_playback::secondaryAuditionHostEligible`) locked by
  `static_assert` over its full truth table; the audible result was confirmed
  manually with a real VST3.

## Known limits

- Recording still captures one armed audio track at a time.
- Capacity for a 10-minute, 150-track project has not been measured.
- Verification on Behringer hardware is still pending.
- Full plugin delay compensation, a dedicated low-latency tracking mode and
  calibrated recording-latency compensation remain future work.
- Autosave runs every 60 seconds when the project has unsaved changes; it is a
  safety net, not a substitute for saving (Ctrl+S).
