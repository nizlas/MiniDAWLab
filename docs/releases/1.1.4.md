## Fixed

- VST3 insert effects now receive DAL’s project tempo through JUCE’s standard
  `AudioPlayHead` → VST3 `ProcessContext` bridge. Tempo-synced effects no longer fall back to
  120 BPM solely because they run in DAL.
- The same transport context is supplied to audio-track Pre/Post inserts, input monitoring,
  instrument inserts, group/master inserts and offline mixdown processing.

## Verification

The built DAL Mono Delay VST3 was loaded through DAL’s production `PluginInsertHost`.
Its default 1/4-triplet echo measured 222.23 ms at stopped 180 BPM and 333.33 ms after switching
to playing 120 BPM without reloading. Full evidence and limitations:
[`VST3_TEMPO_TRANSFER_VERIFICATION_2026-09-28.md`](../VST3_TEMPO_TRANSFER_VERIFICATION_2026-09-28.md).
