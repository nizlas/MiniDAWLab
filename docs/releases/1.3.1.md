# Danielssons Audio Lab 1.3.1

| | |
|---|---|
| Version | 1.3.1 |
| Date | 2026-10-10 |
| Installer | `DanielssonsAudioLab-1.3.1-Setup.exe` |
| Portable | `DanielssonsAudioLab-1.3.1.zip` |

Read-ahead can be turned on or off from Audio Settings. The renderer, which tracks it
adopts, the depth cap and the thread model are unchanged. Parallel strip processing is
unchanged and does not follow this checkbox. Project format stays **v28**.

## New

- **Audio Settings → Enable read-ahead processing.** The checkbox is the next start.
  The dialog also shows `Active this session: On/Off`. When those two differ it shows
  `Restart required`. A start argument shows `Controlled by start argument.`
- **Default on** when `%APPDATA%\MiniDAWLab\read-ahead.xml` has no saved choice, including
  an upgrade from 1.3.0. An explicit Off stays Off across later starts and upgrades.
  Depth stays 3. The file is machine-local, not part of the project, and not an undo step.
- **`--no-readahead`** turns this process off. `--experimental-readahead` and
  `--experimental-readahead=N` (N clamped to 2..8) still turn it on. If several of these
  arguments appear, the last one wins. A start argument is not written to the preference
  file.

## Known

- The checkbox does not start or stop read-ahead inside the running process. Restart DAL.
- The read-ahead behaviour itself is still the 1.3.0 prototype. See `docs/releases/1.3.0.md`
  for the measurements and the AmpliTube shutdown note.
