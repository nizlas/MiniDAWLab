## Fixed

- **A just-rendered proxy no longer turns Stale after save / reopen.** With the instrument loaded,
  the proxy status compared the published generation against a fingerprint whose state component
  is a per-session counter: a generation rendered after any DAL-observed instrument event (e.g.
  opening the plug-in editor) carried a higher revision than a freshly reopened project could ever
  reach, so the organ (VB3-II) showed *Stale* right after reopening although music and sound were
  unchanged — and re-rendering only moved the problem to the next reopen. On load, after the saved
  plug-in state has been restored, DAL now adopts the revision the Save stamped next to that state,
  exactly as the persisted pairing rule intends. Real changes still count: a note edit, or a Save
  made after a later sound edit, keeps the generation Stale. Existing projects need **no new
  Render now**: a generation whose stamps already match (rendered, then saved) reads Current when
  opened with 1.2.1. Report: `docs/PROXY_CURRENCY_AFTER_REOPEN_2026-10-07.md`.
