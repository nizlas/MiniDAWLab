**Mixer window.** Press **F3** (or Window > Mixer) for a separate, resizable mixer with one
channel strip per track in arrangement order and Stereo Out fixed at the right. Report:
`docs/MIXER_WINDOW_2026-10-06.md`; architecture: `docs/CURRENT_ARCHITECTURE.md` "Mixer window"
and "Concurrent per-row meters".

## New

- One mixer window: F3 toggles it from the main window and from the mixer itself; the close
  button hides it and reopening keeps size, position, scroll and section state. Transport
  shortcuts (Space, record toggle, numpad 1), Ctrl+S and undo / redo work with the mixer focused,
  never while you type in a value field.
- Sections that can be shown / hidden for all channels at once from the toolbar: Routing,
  Pre-gain, Pre inserts, Post inserts, Sends, Faders, Meters. Strips stay aligned in every
  combination; faders stretch with the window height; a small window scrolls the whole stack.
- Per track kind: Audio — Audio Input (device channels, mono / stereo pairs), Audio Output,
  pre-gain, inserts, sends, pan, fader, meter, Power / Mute / Monitor / R. Instrument — MIDI Input
  + Input Channel, MIDI Channel, Audio Output, inserts, sends, pan, fader, meter, instrument editor
  / alternatives, Power / Mute / Monitor / R. MIDI track — MIDI Input + filter, MIDI To, MIDI
  Channel, Power / Mute / Monitor / R (no audio controls). Group — Audio Output, inserts, sends,
  pan, fader, meter, Mute. Stereo Out — current device output (information), inserts, fader, the
  Stereo Out meter, Mute.
- Every control edits its own track directly (no need to select it first) through the same
  Session edits, validation, undo steps and recording restrictions as the Inspector; the
  Inspector follows, and vice versa. Inserts: click opens the editor, right-click offers move up
  / down, move to the other stage, remove; "+ Add" opens the VST3 picker.
- Concurrent level meters for every visible strip and Stereo Out, with the Inspector's own meter
  showing the same row at the same time (identical peaks, one acknowledgement clears the overload
  lamp in both). Rows that are not displayed cost nothing on the audio thread.
- Mixer bounds and section flags are remembered per machine in `ui-layout.xml` (next to the
  track-header width); they never dirty a project or create an undo step.
