# Danielssons Audio Lab 1.1.0

| | |
|---|---|
| Version | 1.1.0 |
| Date | 2026-09-20 |
| Installer | `DanielssonsAudioLab-1.1.0-Setup.exe` |
| Portable | `DanielssonsAudioLab-1.1.0.zip` |

Feature release after 1.0.x. Headline change: per-audio-track input selection
and software input monitoring. Project-file schema is **23** (input assignment
on audio tracks). Older projects open unchanged and keep the previous
first-active-input recording source until you pick something else.

## What's new since 1.0.0

- **Software input monitoring** — audio tracks have a speaker toggle next to
  Record-arm. Monitor ON sends the selected live input through the track's
  normal strip (pre-gain, Pre inserts, fader/mute, Post inserts, pan, sends)
  and suppresses that track's clips. Monitor OFF plays clips and does not
  mix live input. Record-arm and Monitor are independent: monitoring does not
  start recording, and an armed track still records with Monitor OFF.
  Monitor is a runtime control (not undo); it defaults to OFF when a project
  is opened.
- **Per-audio-track input selection** — the Inspector lists None, each
  available mono input, and available stereo pairs, using the active device's
  channel names. The same source drives both recording and monitoring.
  Recordings stay raw (before pre-gain, inserts, fader and pan). A mono
  input feeds the stereo strip without doubling its level. Physical channel
  indices stay distinct from packed active-channel positions, including when
  only some inputs are enabled.
- **More than two active inputs** — Audio Settings no longer caps the device
  at two simultaneous inputs. Enable every analog input the interface
  exposes, then choose per track in the Inspector. Unused channels can still
  be left disabled.
- **Unavailable inputs stay honest** — an assignment saved on another machine
  that cannot be resolved here is labelled unavailable and supplies silence.
  The saved assignment is kept so the original device can resolve it again.
- **Waveforms after reload** — recorded clip waveforms appear once peak data
  is ready, without clicking or dragging. Holding the mouse on a clip no
  longer makes the waveform vanish on release.
- **Primary instrument save** — saving a project whose Primary instrument is
  missing no longer destroys that plugin's descriptor and state.

## Known limits

- Recording still captures one armed audio track at a time. Other tracks can
  stay independently assigned and monitored.
- Capacity for a 10-minute, 150-track project has **not yet been measured**;
  no performance certification is claimed for that scale.
- Verification on Behringer hardware is still pending.
- Full plugin delay compensation, a dedicated low-latency tracking mode,
  anticipative processing, and verified/calibrated recording-latency
  compensation remain future work.
- Round-trip latency has not been measured; no universal third-party plugin
  compatibility is claimed (plugins can crash in their own code — crash
  reports are captured under `%APPDATA%\MiniDAWLab\crash-dumps\`).
- Offline mixdown renders project clips and never captures live device input,
  regardless of Monitor state.
- Autosave runs every 60 seconds when the project has unsaved changes; it is
  a safety net, not a substitute for saving (Ctrl+S).
